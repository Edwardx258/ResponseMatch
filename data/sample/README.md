# Sample data (synthetic)

Everything in this folder was written by hand for development and tests. None of it
describes real people, real requests, or real handbook text.

- `volunteers.json` — invented volunteer profiles placed at approximate Seattle
  neighbourhood centres.
- `requests.jsonl` — invented 311-style requests.
- `handbook/` — short placeholder guidance so retrieval has something to return.
  Replace it with public handbooks before measuring anything (see the main README).

Do not report metrics computed on this data as project results.
